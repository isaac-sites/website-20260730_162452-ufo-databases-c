## Introduction

UFO maps are not neutral pictures of where unusual aerial phenomena occur. They are visualisations of where particular reporting systems collect, investigate and publish reports. As a result, the same event can appear prominently in one database yet be absent from another, while entire regions may seem quiet simply because no widely used reporting network operates there. Understanding a UFO map therefore begins with understanding the reporting system behind it.

Different catalogues were built for different purposes. Some exist to encourage public reporting, others to investigate selected cases, and some publish only reports that meet specific administrative or technical requirements. These design choices shape every map they produce, affecting geographic coverage, case density and the kinds of reports available for analysis.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/faq-page" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANFAQ &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANFAQ &#124; GEIPAN</span></span></span>

## Who Each Reporting System Reaches

The first source of variation is the audience that each reporting system serves.

Public reporting databases such as the National UFO Reporting Center ([NUFORC]({{ 'nuforc/' | relative_url }})) are designed to accept reports directly from witnesses with relatively few barriers to submission. This produces a large archive that captures everything from brief lights in the sky to lengthy narrative accounts. Because reporting is voluntary, however, the database reflects where people know about NUFORC, feel motivated to report and have internet or telephone access as much as it reflects the underlying distribution of sightings.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.narcap.org/faa-reporting-recommendation" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: narcap.org">[narcap.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">narcap.org</span><span class="citation-popover-snippet">Platte, John-Michael Guttierez, Ted Roe, Ryan Graves, 2023 — National Aviation Reporting Center on Anomalous PhenomenaJune 14, 2023...</span><span class="citation-popover-meta">Published: June 14, 2023</span></span></span>

By contrast, France's [GEIPAN]({{ 'geipan/' | relative_url }}), which operates within the French space agency CNES, uses a structured intake process centred on a detailed technical questionnaire. Witnesses submit supporting material where available, investigations follow a defined methodology and only eligible aerospace phenomena are accepted. The resulting map represents reports that have entered this official investigative process rather than every observation members of the public considered unusual.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/faq-page" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANFAQ &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANFAQ &#124; GEIPAN</span></span></span>

Other organisations occupy different positions between these models. [MUFON]({{ 'mufon/' | relative_url }}) accepts public submissions but also assigns many cases to volunteer investigators for follow-up. Its published material therefore reflects both public reporting and organisational investigation, while access to detailed case information is more restricted than in completely open databases.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.uapedia.ai/wiki/nuforc-mufon-civilian-data-sources/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uapedia.ai">[UAPedia - Unlocking New Realities]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uapedia.ai</span><span class="citation-popover-title">Unlocking New Realities NUFORC &amp; MUFON: Civilian Data Sources</span><span class="citation-popover-snippet">Unlocking New RealitiesNUFORC &amp; MUFON: Civilian Data Sources - UAPediaNovember 7, 2025...</span><span class="citation-popover-meta">Published: November 7, 2025</span></span></span>

These institutional differences mean that two databases covering the same country can legitimately produce different geographical patterns even before any comparison of the reports themselves begins.

## How Intake and Publication Rules Change the Map

Reporting systems differ not only in who can submit reports but also in what eventually appears on a public map.

Several design choices have particularly large effects:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* **Submission requirements.** A simple online form encourages many reports, whereas lengthy questionnaires reduce participation but often improve data quality.
* **Screening before publication.** Some organisations publish reports soon after receipt, while others investigate or classify cases before release.
* **Eligibility rules.** Government systems may reject reports outside their remit, such as paranormal claims or observations lacking sufficient information.
* **Privacy policies.** Some organisations anonymise reports or withhold precise locations, affecting how points appear geographically.
* **Resource constraints.** Limited investigators or staff can create delays, meaning publication dates do not necessarily match observation dates.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/58788" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMethodology &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMethodology &#124; GEIPAN</span></span></span>

</div>

GEIPAN illustrates how publication policy can reshape a national map. Straightforward cases may be resolved quickly and not proceed to publication, while investigated files are anonymised, classified and released only after processing. Consequently, its public map reflects completed case handling rather than a live feed of incoming reports.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/58788" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMethodology &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMethodology &#124; GEIPAN</span></span></span>

Conversely, a public submission database may display many recent reports because its objective is rapid collection rather than exhaustive investigation. This creates a map with greater temporal immediacy but more variation in report quality and completeness.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.narcap.org/faa-reporting-recommendation" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: narcap.org">[narcap.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">narcap.org</span><span class="citation-popover-snippet">Platte, John-Michael Guttierez, Ted Roe, Ryan Graves, 2023 — National Aviation Reporting Center on Anomalous PhenomenaJune 14, 2023...</span><span class="citation-popover-meta">Published: June 14, 2023</span></span></span>

## Why National Boundaries Often Reflect Institutions Rather Than Phenomena

International comparisons require particular caution because reporting infrastructure varies dramatically between countries.

A country with an active official investigation programme, established civilian reporting organisations and widespread public awareness is likely to accumulate many more records than a country without comparable institutions. Differences in language, media attention, trust in government, internet access and cultural attitudes towards reporting also influence participation.

This means that an apparent national "hotspot" may indicate an efficient reporting ecosystem rather than an unusually high frequency of unexplained aerial observations. Likewise, sparse reporting from another country may reflect the absence of a well-known reporting pathway instead of an absence of sightings.

The resulting maps therefore measure reporting opportunity as much as reported experience.

## What Cross-Database Comparisons Can Reveal

Comparing multiple catalogues is often more informative than relying on any single database.

When similar clusters appear independently across different reporting systems, researchers gain greater confidence that they are observing a genuine reporting pattern rather than an artefact created by one organisation's procedures. Differences between databases can also reveal institutional effects.

For example:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* A concentration appearing only in a public submission database may reflect local publicity or reporting campaigns.
* A cluster surviving both public reporting and official investigation deserves closer examination because it persists despite different intake and filtering rules.
* Regions that disappear entirely when moving from an open database to an investigated database may indicate that many reports were resolved during case assessment rather than representing fundamentally different observations.

</div>

Because many databases contain overlapping cases submitted to multiple organisations, careful matching is necessary to avoid counting the same event more than once.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://p-i-a.com/pia.com/httpdocs/WWC/689688_AnEvaluationofUAPShapesandCharacteristicsPowelletal.pdf/689688_AnEvaluationofUAPShapesandCharacteristicsPowelletal.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: p-i-a.com">[Pia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">p-i-a.com</span><span class="citation-popover-title">Pia SCU</span><span class="citation-popover-snippet">10.5281/zenodo.10287332 The Reported Shape, SDecember 11, 2023...</span><span class="citation-popover-meta">Published: December 11, 2023</span></span></span>

## Reading UFO Maps as Products of Reporting Systems

The most useful question to ask of any UFO map is not simply, "Where are the sightings?" but "What reporting system produced this pattern?"

Every catalogue embodies decisions about who can report, what information is required, which cases are investigated, what is published and how locations are displayed. Those institutional choices influence the resulting geography just as surely as the underlying reports themselves.

Rather than treating competing databases as contradictory, they are better understood as complementary views of different reporting populations. Public submission systems reveal broad witness participation, investigative systems document more structured case assessment, and comparisons between them help distinguish patterns created by reporting practices from patterns that merit closer investigation.

    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
