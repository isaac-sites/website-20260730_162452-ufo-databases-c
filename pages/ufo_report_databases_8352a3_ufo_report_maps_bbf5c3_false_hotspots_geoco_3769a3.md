## Introduction

[UFO report maps]({{ 'report-maps/' | relative_url }}) are only as accurate as the locations assigned to each report. When a witness says only "Manchester", "Phoenix" or "Lyon", a database often has to convert that place name into a single pair of latitude and longitude coordinates before it can display the report on a map. This process, known as geocoding, can unintentionally create dense clusters of markers in city centres even when the original sightings were scattered across suburbs, industrial estates, rural outskirts or nearby villages. The result is an apparent urban "hotspot" that reflects a mapping decision rather than the true distribution of observations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/geocoding-v4-overview?hl=en" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[Google for Developers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocoding API v4 overview &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocoding API v4 overview &#124; Google for DevelopersJuly 20, 2026...</span><span class="citation-popover-meta">Published: July 20, 2026</span></span></span>

## When Map Pins Manufacture a UFO Hotspot

### How place names become coordinates

A UFO report rarely arrives with survey-grade coordinates. Older reports may provide only a town name, while many modern online submissions include a city but omit a street address for privacy. Before the report can appear on an interactive map, the place description must be translated into coordinates through a geocoding service or a gazetteer—a database of named places.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/overview" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[Google for Developers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocoding API overview &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocoding API overview &#124; Google for Developers...</span></span></span>

When the location is imprecise, the geocoder must choose a representative point for the named place. Depending on the mapping system, that point may be:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the administrative centre of the city;
* a calculated geographic centroid;
* the historic town centre;
* the centre of the mapped urban boundary; or
* another standard reference point associated with the place name.

</div>

None of these locations necessarily corresponds to where the witness actually made the observation. They merely provide a convenient coordinate that allows the record to be displayed on a map.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/geocoding" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[Google for Developers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocode an address &#124; Geocoding API &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocode an address &#124; Geocoding API &#124; Google for DevelopersJuly 20, 2026...</span><span class="citation-popover-meta">Published: July 20, 2026</span></span></span>

### Why default map points create clusters

The bias appears when many reports share the same broad place name.

Imagine fifty witnesses over several decades reporting sightings from different parts of Birmingham. Some observations occur near the airport, others from northern suburbs, parks or surrounding countryside. If every report simply lists "Birmingham" and the database assigns them all to one central coordinate, every marker will occupy essentially the same position.

On the finished map this produces what looks like a remarkably dense hotspot. In reality, the reports may be spread across hundreds of square kilometres.

The distortion becomes stronger because interactive maps display overlapping markers as a single dense stack or a visually striking cluster. Zooming out reinforces the illusion that the city centre experienced an exceptional concentration of sightings when, in fact, the clustering originated during data processing rather than in the observations themselves.

[NUFORC]({{ 'nuforc/' | relative_url }}) explicitly cautions that its public map contains city-level locations and that reports tend to cluster where only a city name is available, illustrating exactly this form of geocoding artefact rather than necessarily indicating a genuine concentration of events.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/overview" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[Google for Developers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocoding API overview &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocoding API overview &#124; Google for Developers...</span></span></span>

## Why the Bias Matters for UFO Analysis

Artificial clustering affects several common interpretations of UFO databases.

First, it can exaggerate apparent urban hotspots. Researchers comparing cities may conclude that one downtown area generated unusually large numbers of reports, when many reports actually originated throughout the wider metropolitan region.

Second, spatial statistics can become misleading. Techniques designed to identify genuine geographic concentrations assume that mapped coordinates approximate the observation location. If hundreds of records share identical fallback coordinates, statistical hotspot analyses may detect significance driven partly by duplicated locations rather than by an underlying phenomenon.

Third, comparisons with environmental features become less reliable. Analysts may incorrectly associate sightings with airports, military facilities, coastlines or geological features simply because the assigned city-centre coordinate happens to lie near those landmarks, even though the original observation occurred elsewhere.

This is why careful spatial studies distinguish between precise observation coordinates and approximate locality references whenever possible, rather than treating every point as equally accurate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/geocoding" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[Google for Developers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocode an address &#124; Geocoding API &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocode an address &#124; Geocoding API &#124; Google for DevelopersJuly 20, 2026...</span><span class="citation-popover-meta">Published: July 20, 2026</span></span></span>

## Ways to Test and Correct Geocoding Bias

Researchers have several practical methods for identifying whether city-centre pins are manufacturing apparent hotspots.

**Inspect repeated coordinates.** If dozens or hundreds of reports from a large city share exactly the same latitude and longitude, they almost certainly reflect a default geocoding choice rather than identical observation locations.

**Record spatial uncertainty.** Instead of treating every coordinate as equally precise, databases can distinguish between exact GPS positions, street-level locations, neighbourhood-level locations and city-level approximations. This allows analyses to account for different levels of positional confidence.

**Use larger geographic units.** If reports only identify a municipality, mapping them as belonging to that administrative area rather than a single point often provides a more honest representation.

**Compare coordinate precision.** Analysts can test whether apparent hotspots persist after excluding reports with only city-level locations. If the hotspot disappears, the clustering was probably driven by geocoding rather than observation patterns.

**Preserve the original location description.** Retaining the witness's text alongside derived coordinates allows later researchers to improve the geocoding as better geographic information becomes available, rather than treating an estimated point as permanent.

These approaches are common practice in geographic information systems because geocoding is recognised as an interpretive step rather than a neutral conversion of text into location.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://developers.google.com/maps/documentation/geocoding/geocoding" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: developers.google.com">[google.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">developers.google.com</span><span class="citation-popover-title">for Developers Geocode an address &#124; Geocoding API &#124; Google for Developers</span><span class="citation-popover-snippet">Google for DevelopersGeocode an address &#124; Geocoding API &#124; Google for DevelopersJuly 20, 2026...</span><span class="citation-popover-meta">Published: July 20, 2026</span></span></span>

## A Map Pin Is Not the Observation

The most important lesson is that a map marker represents the database's best available estimate of location, not necessarily the place where the witness stood. In UFO catalogues, many reports originate from incomplete place descriptions, forcing compilers to choose a representative coordinate. That decision is essential for mapping, but it also introduces the possibility of artificial hotspots.

For this reason, dense clusters in city centres should be interpreted cautiously. They may indicate genuine concentrations of reports, but they may equally reflect the routine geocoding practice of assigning broad place names to a single default point. Distinguishing between those two possibilities is a necessary first step before drawing conclusions from the geography of UFO reports.

  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
